# Cerberus MGM Boot — Concept

Related docs: [[frame_plan]], [[prompt_bank]], [[project_scope]]

## Core Image

A black screen fades into a circular crest like an old movie studio mark.

Inside the ring: Cerberus, the three-headed guardian dog.

The tone should feel like:

- classic movie-studio intro
- mythic security emblem
- cartoon noir
- slightly ridiculous in the best possible way
- not generic cyberpunk slop

## Head Personalities

### Left Head — The Sentinel

Alert, scanning, ears up. This head represents watchfulness and situational awareness.

### Center Head — The Roarer

The classic movie-logo roar posture. This is the dramatic center of the animation.

### Right Head — The Cigar Head

A cigar-smoking old bastard. Calm, unimpressed, possibly amused. This head gives the animation humor and personality.
