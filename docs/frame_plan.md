# Frame Plan

Target bootanimation format:

    1344 2992 30
    p 1 0 part0
    c 0 0 part1

## Part 0 — Intro

Plays once.

Suggested sequence:

1. Black screen
2. Faint ring appears
3. Crest text fades in
4. Cerberus silhouette appears
5. Three heads become visible
6. Center head prepares to roar
7. Cigar ember flickers
8. Ring pulses

Approximate duration: 1.5–2.5 seconds.

## Part 1 — Loop

Repeats until Android finishes booting.

Suggested sequence:

1. Center head roars
2. Left head scans
3. Right head cigar ember glows
4. Smoke curls subtly
5. Crest pulses once
6. Text changes between WATCHING THE GATES and SYSTEM ONLINE

Approximate loop duration: 1–2 seconds.

## Frame Naming

Android bootanimation frame files should be sequential:

    part0/00000.png
    part0/00001.png
    part0/00002.png

    part1/00000.png
    part1/00001.png
    part1/00002.png
